# MyFOC

基于 GD32F303、DRV8323 和 AS5047P 的三相电机 FOC 控制固件，用于轮足机器人的腿电机与轮电机控制。

一块驱动板控制一个电机。通过编译配置区分左腿、左轮、右腿、右轮，四块板可共用一条 CAN 总线。

当前实现：

- 电流模式：Iq 电流闭环，Id 目标为 0。
- 速度模式：速度环、电流环串级控制。
- 位置模式：位置环、速度环、电流环串级控制。
- 电角度零偏校准及 Flash 保存。
- 串口目标设置、PID 参数调整和数据输出。
- CAN 分组控制，四电机位置、速度、电流及状态主动反馈。

本文对应当前源码中的协议：**单位：位置 rad、速度 rad/s、电流 A**
                        **CAN下发为4位模式＋有符号24位整数数值（编码*10000）**
                        **反馈为float，第一帧当前电流、速度，第二帧当前位置、模式、错误、校准、状态**
## 1. 硬件与开发环境

## 3. 电机配置

```c
#define MOTOR_LEG_WHEEL 0   // 0：腿，1：轮
#define MOTOR_LEFT_RIGHT 0  // 0：左，1：右
```

四种配置与 CAN ID 的对应关系：

| 电机 | LEG_WHEEL | LEFT_RIGHT | 接收控制ID | 电流/速度反馈ID | 位置/状态反馈ID |
|---|---:|---:|---|---|---|
| 左腿 | 0 | 0 | 0x101 | 0x201 | 0x211 |
| 左轮 | 1 | 0 | 0x101 | 0x202 | 0x212 |
| 右腿 | 0 | 1 | 0x102 | 0x203 | 0x213 |
| 右轮 | 1 | 1 | 0x102 | 0x204 | 0x214 |

同一侧两块板接收同一控制ID，分别读取前、后4字节；反馈ID各自独立。四块板应分别配置、编译和下载。

当前电机参数：

| 电机 | 型号 | 极对数 PP | 减速比 G | DIR |
|---|---|---:|---:|---:|
| 左腿 / 右腿 | GIM6010-8 | 14 | 8 | -1 |
| 左轮 | M0603A_111 | 10 | 1 | 1 |
| 右轮 | M0603A_111 | 10 | 1 | -1 |

更换电机、编码器安装方式或减速机构后，应核对 `PP`、`G`、`DIR`、PID 和腿限位，并重新校准。

## 4. 程序结构

![程序结构流程图](images/program-structure.png)

控制主路径：

```text
TIMER0_CH3触发ADC
    → ADC转换完成中断
    → 电流换算、编码器角度/速度更新
    → 电角度计算、Clarke/Park变换及滤波
    → 根据模式执行电流/速度/位置控制
    → SVPWM更新三相占空比

TIMER5中断 → 每1ms控制RGB灯、每5ms提交两帧CAN反馈

CAN0FIFO非空中断 → 读取CAN指令解析

主循环 → 校准任务、VOFA打印数据、错误处理
```

## 5. 腿电机的限幅

腿电机对外位置：**0为收腿，数值增加表示伸腿，范围约0～0.56199602 rad（32.2°）**。

内部限位来自 `User/Mydef.h`，属于当前机构的标定值：
| 电机 | 收腿端位置 rad | 伸腿端位置 rad |
|---|---:|---:|
| 左腿 | -0.16388642 | -0.72588244 |
| 右腿 | -0.61749749 | -0.05550147 |


## 6. 首次运行与校准

1. 完成角色配置和固件下载，上电等待电流零偏采样结束，串口输出 `Init Over`。
2. 检查角度、速度及电流反馈。若未保存过有效校准数据，先执行一次模式4。
3. 校准期间产生定位力矩，程序计算电角度零偏并写入 Flash，然后返回停止模式。
4. 判断反馈的校准标志位，再下发运行目标。

校准数据读取、保存实现位于 `CODE/BSP/Flash.c`；当前地址为 `0x0803FC00`，使用魔数判断记录是否存在。调整芯片容量或链接布局时，应同步核对该地址及擦除页范围。

## 7. 串口协议

串口为 **USART2，115200，8N1**。命令使用文本，**以换行符 `\n` 结束**。

| 命令 | 含义 |
|---|---|
| `m0` | 停止输出 |
| `m1` | 电流模式 |
| `m2` | 速度模式 |
| `m3` | 位置模式 |
| `m4` | 执行一次校准 |
| `c1.0` | 设置电流目标1 A |
| `v1.0` | 设置速度目标1 rad/s |
| `p0.1` | 设置位置目标0.1 rad |

PID参数可通过串口修改，命令后直接跟数值：

| 控制环 | Kp | Ki | Kd |
|---|---|---|---|
| 位置 | kpp | kip | kdp |
| 速度 | kpv | kiv | kdv |
| Iq | kpq | kiq | kdq |
| Id | kpd | kid | kdd |

## 8. CAN下发协议

使用 **经典CAN、1Mbps、11位标准数据帧、DLC=8**。左侧控制ID为 `0x101`，右侧为 `0x102`。

| 字节 | 内容 |
|---|---|
| 0 | 腿电机模式 |
| 1～3 | 腿电机目标，有符号24位，大端 |
| 4 | 轮电机模式 |
| 5～7 | 轮电机目标，有符号24位，大端 |

模式0停止、1电流、2速度、3位置、4校准
每帧同时包含同侧两个电机的命令；另一半填模式0表示停止该电机，不表示忽略。

数据编码与解码：

```text
发送：整数 = round(目标 × 100000)，以24位补码发送，高字节在前
接收：目标 = 有符号整数 / 100000.0
```

| 操作 | CAN数据 |
|---|---|
| 腿停止，轮速度+10 rad/s | `00 00 00 00 02 0F 42 40` |
| 腿停止，轮速度-10 rad/s | `00 00 00 00 02 F0 BD C0` |
| 腿位置0.5 rad，轮停止 | `03 00 C3 50 00 00 00 00` |
| 腿校准，轮停止 | `04 00 00 00 00 00 00 00` |
| 腿停止，轮校准 | `00 00 00 00 04 00 00 00` |
| 同侧两个电机停止 | `00 00 00 00 00 00 00 00` |

## 9. CAN反馈协议

每块板每5 ms主动提交两帧

**反馈float采用小端IEEE 754单精度（使用memcpy接收）** 

第一帧：

| 字节 | 内容 | 类型 / 单位 |
|---|---|---|
| 0～3 | 实际Iq | float / A |
| 4～7 | 实际速度 | float / rad/s |

第二帧：

| 字节 | 内容 | 类型 |
|---|---|---|
| 0～3 | 实际位置 | float / rad |
| 4 | 当前模式 | uint8_t；0～4同控制模式，0xFF为故障 |
| 5 | 错误码 | uint8_t |
| 6 | 已校准标志 | 独立0/1字节 |
| 7 | 正在校准标志 | 独立0/1字节 |

错误码：

| 数值 | 含义 |
|---|---|
| 0 | 无错误 |
| 1 | 未校准 |
| 2 | DRV8323驱动错误 |
| 3 | 模式设置错误 |
